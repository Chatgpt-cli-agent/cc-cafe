# Sims 4 Mod Manager 

The Sims 4 Mod Manager is an application designed to help Sims players create or maintain order in their mod folders. 
The original version (b1.0.0 - b1.0.9) was based on JavaFX. This repository contains the newer version (b1.1.0 - newer) which is based on Electron and Angular. 

![Example](src/assets/images/window.png "Image")

## Installation
First clone this repository and open a terminal/CMD in it. Using
```
npm install
```
all required modules will be installed.

## Run application
Open full application:
```
npm run electron
```

Only run angular:
```
ng serve
```

## Build

```
npm run make
```
